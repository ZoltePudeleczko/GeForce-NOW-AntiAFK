# Nvidia GeForceNOW AntiAFK

[![GitHub release](https://img.shields.io/github/v/release/ZoltePudeleczko/GeForce-NOW-AntiAFK.svg)](https://github.com/ZoltePudeleczko/GeForce-NOW-AntiAFK/releases)

Un pequeño script de autohotkey que debería detener el sistema de inactividad (AFK) de GeForce NOW.

## ¿Cómo funciona?

Mientras el programa detecta que GeForce NOW está en ejecución, envía una pulsación de tecla 'F13' cada 4 minutos. Según mis pruebas, es suficiente para detener el sistema de detección de inactividad (AFK).

Puedes dejar este programa ejecutándose en segundo plano de forma segura y solo se activará cuando inicies una sesión de GeForceNOW.
